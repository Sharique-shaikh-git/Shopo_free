## 1. Executive Summary

### Business Model

**Model:** Vertical SaaS (Software as a Service) with Freemium Pricing

**Core Offer:** Mobile-first, AI-powered store builder for Pakistani shopkeepers

**Revenue Model:**
- Free tier (acquire users)
- Paid tiers (monetize power users)
- Transaction fees (monetize payments)
- Marketplace (monetize services)

**Target:** 107,100 users by Year 3, generating 1.28 billion PKR (~$3.8M)

### Key Numbers

| Metric | Year 1 | Year 2 | Year 3 |
|--------|--------|--------|--------|
| **Users** | 21,420 | 64,260 | 107,100 |
| **Revenue** | 128M PKR | 578M PKR | 1.28B PKR |
| **Costs** | 85M PKR | 250M PKR | 450M PKR |
| **Profit** | 43M PKR | 328M PKR | 830M PKR |
| **Margin** | 33% | 57% | 65% |

## 4. Pricing Strategy

### Pricing Philosophy

**Principle:** "Affordable for shopkeepers, profitable for us"

**Key Rules:**
1. Price in PKR (not dollars)
2. Free tier must be generous
3. Paid tiers must provide clear value
4. No hidden fees
5. Easy to understand

## 10. Unit Economics

### Customer Lifetime Value (LTV)

```
┌─────────────────────────────────────────────────────────────┐
│                CUSTOMER LIFETIME VALUE                       │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  ASSUMPTIONS:                                                │
│  ├── Average revenue per user (ARPU): 800 PKR/month         │
│  ├── Average customer lifespan: 24 months                    │
│  ├── Monthly churn rate: 5%                                  │
│  └── Gross margin: 80%                                       │
│                                                              │
│  LTV CALCULATION:                                            │
│  LTV = ARPU × Gross Margin × (1 / Churn Rate)               │
│  LTV = 800 × 0.80 × (1 / 0.05)                              │
│  LTV = 800 × 0.80 × 20                                      │
│  LTV = 12,800 PKR                                            │
│                                                              │
│  LTV BY TIER:                                                │
│  ├── Free tier: 0 PKR                                        │
│  ├── Basic: 500 × 0.80 × 20 = 8,000 PKR                     │
│  ├── Pro: 1,500 × 0.80 × 20 = 24,000 PKR                    │
│  └── Enterprise: 3,000 × 0.80 × 20 = 48,000 PKR             │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```
