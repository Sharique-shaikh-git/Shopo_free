# Project Genesis — SHOPO

## What is SHOPO?
A mobile-first AI-powered store builder for non-technical Pakistani merchants.
- Working title: **SHOPO** (not finalized)
- Previously called: Digital Dukaan

## Why We're Building This
- [[02_Architecture/problem-statement]]
- Pakistani shopkeepers waste hours on WhatsApp negotiation
- Shopify is too expensive and too technical for local market
- 80-91% of Pakistan uses Cash on Delivery

## Core Team Setup
- **Founder**: Solo developer (shopkeeper's son — understands the problem firsthand)
- **AI Agents**: Multiple models working in coordination
  - Claude Opus 4.6 (complex), Sonnet 4.6 (medium)
  - Gemini Flash (routine), MIMO 2.5v + Kimi K2.6 (free tasks)

## Tech Stack
- See [[02_Architecture/tech-stack]] for full details
- All free tier: Supabase + Vercel + Railway + Upstash + Cloudflare
